| Game | Page | URL |
|---|---|---|
| Rope Swing | Privacy policy | https://sumar7.github.io/sumartech-legal/rope-swing/privacy.html |
| Stack Drop | Privacy policy | https://sumar7.github.io/sumartech-legal/stack-drop/privacy.html |

Each game keeps the source copy in its own repo (`public/privacy.html`). After changing one there, copy it
here and push: the site updates within a minute or two.
